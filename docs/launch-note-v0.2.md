# FTFN v0.2 Launch Note

Status: public-facing draft; publication requires preview verification and explicit launch approval.

## The Future Is A Stack Of Dependencies

FTFN is a future-state intelligence project about what could be, what it depends on, and what could stop it from happening.

Most future-facing coverage starts with an invention, a company claim, or a dramatic forecast. FTFN starts one layer lower. It follows the materials, infrastructure, standards, institutions, funding, workforce, climate conditions, and local delivery systems that decide whether a possibility becomes real.

Version 0.2 is the first complete authority-loop candidate. The current owner-only build includes:

- 16 Published signals grounded in official, primary, or clearly labeled credible-analysis sources,
- a 128-source evidence library with visible freshness and review metadata,
- an Atlas connecting topics, sources, organizations, technologies, local systems, evidence gaps, and dependency maps,
- a public method and publication policy,
- an eight-entry update and correction log,
- versioned static exports for public source, topic, and Published-signal metadata.

The Published set is deliberately mixed. It includes climate outlook, critical-minerals data and funding, AI-for-materials research, post-quantum standards, data-centre electricity pressure, federal crash-reporting rules, semiconductor-materials funding, space-hardware integration, plant-breeding awards, storage-manufacturing funding, a large-load electricity tariff, one named electric-service project, and municipal housing-intention and delivery baselines. Each record states what the source supports and what it does not.

That restraint is part of the product. Aggregate analysis is not local capacity. Crash reports are not normalized safety rankings. A funding opportunity is not an award, and an award is not a result. Hardware integration is not launch readiness. A prize is not manufacturing deployment. A tariff is not proof of available capacity. One project is not regional readiness. A permit or development pipeline is not completed housing.

FTFN uses 42 as possibility and 59 as urgency. The goal is not to predict a single future. It is to make the dependency stack visible enough that readers can see where choices, constraints, and evidence meet.

Civilization is a choice.

## Current Limitations

- Twenty signals remain In Review; they are visible as research material but are not Published intelligence.
- The two local-system profiles are constraint maps, not final readiness assessments.
- The briefing and dependency maps remain prelaunch editorial material.
- Source freshness is generated from recorded checks; FTFN does not yet perform live automated ingestion or publishing.
- The JSON datasets are static build exports, not a live API with uptime guarantees.
- There are no accounts, alerts, analytics, newsletter capture, numeric 42/59 scores, or database-backed public application.
- An owner-only preview exists and has passed hosted checks. Public access, package freeze, `ftfn.io` attachment, Hostinger DNS changes, and public launch still require separate approval.
