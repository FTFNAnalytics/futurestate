# Phase 123 — Matched Delivery Dossiers

**Status:** Complete<br>
**Effective date:** 2026-08-30
**Program:** FTFN v0.5 — The Evidence Fieldbook

## Purpose

Turn the twelve existing cross-system stories into stable comparative reading files. The phase compares evidence structures and stopping points, not project performance.

## Delivered

- 12 explicit dossier records on the existing Phase 105 routes.
- 149 existing Published signal links and 124 inherited, resolved source links.
- Every enhanced route exposes the exact source provenance rail; no non-Published signal is promoted or counted as Published context.
- A comparison passport for identity, period, unit, denominator, provenance, method and verdict.
- One Fieldbook index and one public JSON export.

## Comparison boundary

Every dossier is fixed at `Context only`. No shared performance denominator, normalized measure, effect size, causal estimate, score or ranking is created. A dossier may reveal that evidence is incompatible or missing; it may not repair that gap by inference.

## Completion standard

Phase 123 is complete when all twelve Phase 105 story IDs resolve one-to-one, all selected projects and places resolve through Phase 119, every selected signal exists and is already Published, every source ID resolves and is exposed on the enhanced route, every passport preserves incompatible periods and denominators, and future evidence gates remain unchanged.
