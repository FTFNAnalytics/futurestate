## Interpretation boundaries

- Not publicly acquired does not mean nonexistent, withheld, or never submitted.
- An acquisition ticket is a retrieval control, not evidence that a document exists.
- A repository portal is a routing source, not the exact implementation artifact.
- Adjacent evidence cannot fill an unsupported directive element by inference.
- A page-level FTFN match is not GAO acceptance.
- Recommendation status, implementation, closure, entity evidence, operating outcome, ranking, readiness, safety, savings, value, and causation remain separate.
