## Interpretation boundaries

- A second-order locator is not the target artifact.
- A plan to assess is not a completed assessment.
- A procurement forecast is not an award, deployed system, or operating control.
- A generic AAR template is not HHS's department-wide SOP or proof that the SOP was used.
- Governance authority and portfolio spend measures are not category-specific savings goals.
- A pre-recommendation analysis cannot satisfy a post-recommendation directive by inference.
- GAO acceptance, implementation, closure, entity evidence, operating outcomes, ranking, readiness, savings, value, and causation remain separate.
