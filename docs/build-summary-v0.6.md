# FTFN v0.6 Build Summary

**Edition:** Open Evidence Review<br>
**Completed:** 2026-08-30<br>
**Phases:** 125–129
**Status:** Complete and release-validated locally. GitHub publication and hosted deployment remain separate owner-controlled actions.

## Outcome

v0.6 turns the v0.5 Evidence Fieldbook into a record-by-record public review layer. Readers can now move from a Published signal to a bounded source annotation, inspect a requirement-level mission screen, follow a named project or place biography, read a four-horizon topic synthesis, and stop at an explicit cross-system compatibility boundary.

The edition adds six canonical hubs and substantively enhances 218 existing routes, producing 224 new or enhanced public surfaces. It adds six direct schema-1.0 JSON exports. It does not add a source or signal, admit an artifact, answer a mission, close an acquisition gap, advance an Atlas stage, operate a future evidence gate, create an observation or outcome, or publish a score, rank, recommendation, forecast or causal finding.
