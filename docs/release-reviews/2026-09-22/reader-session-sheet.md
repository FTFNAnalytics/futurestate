## Accessibility session

Test keyboard focus/order and visible focus, real assistive-technology reading, 200% enlargement, narrow reflow, headings, table semantics, source-link names and English-format switching. Record actual observations and affected routes. A browser shortcut that does not change zoom is not a passed enlargement test.

Automated link, structure and page-size checks are necessary but do not certify accessibility or reader comprehension. Critical observed defects require correction and retest before acceptance.
