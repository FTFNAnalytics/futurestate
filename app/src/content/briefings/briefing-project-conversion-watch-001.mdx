## What changed

Phase 61 converts five local corridors and three technology-adoption rails into named files. Each file identifies the entity, current evidence stage, established record, unresolved stage, exact next artifact, date or reopening trigger, and stop rule. The work does not add a readiness score or promote an underlying signal.

Toronto provides the clearest bounded advancement: Council adopted item `2026.SC33.9`. That closes the scheduled decision stage while leaving enactment conditions, permitting, construction, completion, and occupancy open. TSMC Arizona, Golden-Mars and GS-5, the Space Coast facilities, and the Nevada lithium projects all retain similarly explicit downstream boundaries.

The three adoption cases make the same distinction at institution and operator level. GSA offers a procurement path before a named PQC migration. NIST ARIA offers a multi-level evaluation pilot before continuous assurance. CPUC supplies Waymo service authority before a compatible persistent-outcome series.

## Reader contract

Use the public project-conversion registry to locate the exact artifact that can change a file. A project or adoption file advances only when that artifact is captured and its assigned dossier, pathway, map, local system, gap, and update surfaces are reconciled. No material change is a valid decision; silence is not.
