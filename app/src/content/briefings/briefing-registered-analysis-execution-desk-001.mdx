## Why execution needs a separate authorization

A Phase 72 design registration freezes the proposed research logic. It does not authorize someone to run code, inspect results, change inputs, retry until a preferred output appears, or publish a conclusion. Phase 73 gives execution its own identity, reviewers, receipt, and fail-closed state.

All thirty-two execution dockets remain **Inactive - No Registered Design**. There is no input snapshot, code commit, environment digest, runner, log, output, deviation, replication, reviewer, or receipt.

## Fourteen execution gates

Every future execution must resolve the registered design, freeze its inputs, bind immutable code and environment identity, lock the plan and estimand, commit randomness, constrain runner authority, pass preflight tests, preserve blinding, write an immutable log, enumerate all outputs, capture deviations, support independent replication, and receive dual review with complete propagation.

Passing these gates authorizes only the bounded execution state. It does not validate an effect, support a claim class, or authorize unblinding.

## Frozen input, code, and environment

The input snapshot records every source, version, period, inclusion, exclusion, checksum, and lineage receipt. The execution also binds the repository, commit, dependency lock, runtime or container, architecture, locale, and environment digest.

Reproducibility is not a claim of validity. It lets a second authorized reviewer recover what ran, on which records, with which rules, and under which environment.

## Blinding, logging, and outputs

Result visibility is explicit. Blind-break authority, masking, leakage tests, prohibited inspection paths, warnings, retries, failures, exclusions, diagnostics, and every output appear in durable manifests. A hidden rerun or omitted output is a protocol event, not editorial cleanup.

## Deviations and independent replication

Planned and unplanned departures are recorded before interpretation, including when they were discovered and whether they alter the estimand. Silence never means no deviation.

Independent replication is a separate execution identity. Agreement does not erase common input or design failures; disagreement remains visible and blocks automatic publication.

## Execution boundary

The [Analysis Execution And Result Registry](/evidence/analysis/) and [public export](/data/analysis-execution-result-adjudication.json) expose empty execution contracts. They contain no registered design receipt, frozen bundle, authorized run, unblinded result, deviation, replication, reviewer decision, or receipt.

## Phase 74 evidence synthesis and decision translation

[Evidence Synthesis Desk 001](/briefings/evidence-synthesis-desk-001/) and the [Challenge And Decision Translation Desk](/briefings/challenge-decision-translation-desk-001/) add thirty-two inactive synthesis-input dockets and eight each of synthesis-contradiction, external-challenge, and decision-translation/reevaluation controls. They create zero adjudicated-result inputs, syntheses, contradictions, evidence grades, challenge decisions, recommendations, authorizations, reevaluations, corrections, withdrawals, scores, rankings, receipts, or stage changes.
